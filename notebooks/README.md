# Historical notebooks

`LeakDetection-original.ipynb` is the original exploratory notebook, preserved unchanged. Its dependencies are recorded in `requirements.txt`; they are separate from the runnable dashboard environment.

The newer paired detector/locator reference is preserved at [`dashboard/docs/reference/LeakDetectionV3.ipynb`](../dashboard/docs/reference/LeakDetectionV3.ipynb). The [compatibility review](../dashboard/docs/v3-compatibility.md) documents stale cells and path inconsistencies that prevent treating it as a verified clean top-to-bottom training script.

For running the application and importing existing trained models, start with the [project README](../README.md). For training continuation from a matching pair, use Model lab in the dashboard. No trained weights or datasets are bundled here.
